# 用量与计量

[English](USAGE.md) · [额度设计](zh-CN/report/额度管理中心设计方案.md) · [网关](../backend/service/src/gateway/README.zh-CN.md)

## 指标与时间

| 指标 | 含义 |
| --- | --- |
| 首页合计 | 服务本地日历的当日 |
| Key 合计 | 长期明细与压缩汇总 |
| 上报 Token | 来自上游/适配器的 usage |
| 估算费用 | 本地价格及计费模型，统一 USD |
| 缓存命中率 | 缓存输入除以有效输入，无分母时未知 |
| 前日对比 | 按服务本地日前后比较，比例变化使用百分点 |

无样本不是零。有日期的空白日可表示零活动，无日期旧用量不能放进日历；统计请求失败显示错误，不补造合计。

## 持久化与权限

按日历史独立于请求明细保留，迁移 074 保存/回填已有日期数据。旧压缩数据仍计入长期合计，但不能虚构日期；确认下界的计数明确标示。

成员只接收自己 key 的统计，管理员可看更广汇总；不能以浏览器过滤替代服务端权限。

## 结算与预算

服务 trace/key 身份去重最终结算。请求日志与 Token 统计同事务，钱包在立即事务中只扣一次；新的逻辑请求仍独立计费。

速率、并发和累计额度分别控制。受限文本 key 需要正的输出上限以保守预留；提供商隐藏上下文/媒体及跨进程、崩溃一致预留仍有额外限制。本地费用在与受支持供应商账单对账前属于估算。

## 展示

热力图对日期用量使用同一尺度并支持横向导航。可见区间与长期总计范围不同，颜色同时配日期、数值和可访问标签。
