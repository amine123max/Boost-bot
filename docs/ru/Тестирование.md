# Проверка сборки и работы

Отдельные каталоги тестов и специальные средства их запуска удалены; встроенные в исходные файлы модульные тесты Rust сохранены. Из корня репозитория выполните `pnpm -C frontend run build:desktop`, `npm --prefix bot run build` и `cargo test --workspace --locked`. Требования к среде и проверка работающего приложения описаны в [руководстве репозитория](../../TESTING.md). Подключение реальных моделей и каналов проверяется отдельно в изолированной среде с авторизацией.
