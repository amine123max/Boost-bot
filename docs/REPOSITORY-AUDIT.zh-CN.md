## 历史范围

2026-11-11 的审查覆盖目录、构建路径、文档与确认过时文件，不构成全平台安全审计。历史调整将 apps 前端迁至 frontend、原桌面壳迁至 backend/desktop、crates 迁至 backend，并将 Nginx 归并至根目录；Bot 保留。

历史记录报告移除 36 项：8 个不可达前端模块、12 个依赖缺失上游环境的 Bot 脚本、2 个上游专属测试和 14 个被维护指南替代的 Markdown。运行技能、persona、模板、锁文件、迁移和第三方声明保留。本轮不把这些历史数字当作新执行结果。

## 当前审查原则

| 领域 | 要求 |
| --- | --- |
| 来源 | 目录与职责对应当前 Cargo、Tauri、Vite 和 Node 入口 |

## 已修订事项

本轮补全根 MIT 许可授权文本，新增加密依赖说明、技术数据流和模块图、双语指南、签名发行约定及负载证据。发布目标为 Windows x64 便携/NSIS、macOS arm64 DMG；不存在历史文档所称的全部桌面平台产物。
