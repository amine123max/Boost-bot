# 文档维护规范

[English](DOCUMENTATION.md) · [文档索引](README.zh-CN.md)

## 读者与层次

公开指南维护英文/简体中文两份。根和模块 README 帮助评估、启动和贡献；架构、配置、协议、部署与验收放入专题。

README 保留品牌、社区致谢、平铺标签和留白的当前配图、技术范围、整体数据流、最新发行入口与 Star 曲线。细分技术图放架构指南，不在首页堆叠版本 UI 琐事或重复 API 示例。

## 版本配套

| 文档 | 约定 |
| --- | --- |
| 根/模块指南 | NAME.md 与 NAME.zh-CN.md |
| 既有语言手册 | docs/en、docs/zh-CN，通过映射关联 |
| 发布说明 | 对应中英文件，工作流发布双语内容 |
| 第三方法律文本 | 翻译解释，授权原文保持不变 |

[配对表](documentation-pairs.json)登记全部维护的公开指南。既有俄/韩是额外语言；内置 persona、技能指令和模板 Markdown 属于运行/上游输入，不能因公开文档整理重命名其入口。实施计划与任务记录仅在本地维护，不纳入 Git；运行资料保留语义和来源，不用空壳译文冒充翻译。

行为/默认值修改在同一交付更新两种语言，要求范围等价，不要求字数相同。导航和图表指向对应语言，单文件双语标题不等于两份维护。

## 技术准确性

写清当前行为、有效限额、身份/进程边界与失败语义，区分规划、内联/mock 证据、真实上游和平台检查。默认值/方法引用当前源码，可重复清单从分发生成。

配置表含类型、默认、必填、作用域与说明，启动私有字段区别于运行设置。示例无真实秘密，无样本指标保持未知。

## 链接、图片与证据

仓库链接相对路径，外链注明用途。图片提供 alt、版本范围，不带私有数据；保持比例、留白和同级标签。架构先小型业务流，再分别画 RPC、推理、存储、Bot 和 Nginx。

测量写明硬件、构建、负载、时长、体积及 mock/真实来源；区分成功与拒绝延迟，不能用短样本证明永不泄漏或过载。

## 审查与发布

执行仓库和文档检查，核对配对覆盖、链接、图、截图、依赖与最新发布入口。命令及结果真实记录，未在干净机器/目标平台执行的检查明确保留。

当前工作流用于发布构建，不虚构 PR CI。版本、源提交、签名清单和产物必须一致，过时承诺与平台清单随实现更新。
