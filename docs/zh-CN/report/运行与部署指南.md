# 运行与部署

[English](../../en/report/runtime-and-deployment-guide.md)

## 部署选择

| 模式 | 进程 | 正常入口 |
| --- | --- | --- |
| 桌面 | Tauri 受管 Rust 与 Node Bot | 原生窗口/本地模型网关 |
| 直接 Web | Service + Web，按需 Bot | 12000 |
| 反向代理 | Nginx 加选定 Web/模型路径 | HTTPS 虚拟主机 |
| Bot sidecar | 可选 FastAPI 位于 Boost Web 前 | 配置的 /boost-bot/ |
| 容器 | 一体化或分离 Compose | 发布的 Web 端口 |

准确命令和原生依赖见[构建指南](../../BUILDING.zh-CN.md)，Vite 不是完整 Web 运行时。

## 运行约定

存储可写且持久，内部 RPC 凭据一致，所有打开主库的进程使用相同密钥来源。环境文件位于程序旁；无界面采用私有挂载密钥，桌面可用系统凭据库。

审查实际监听、已保存模式、IPv6 和端口发布。客户端不能指定 actor/内部凭据，模型 key 和 Web 会话保持各自鉴权。

## 生命周期与容量

启动器仅守护自己的子进程，有界退避重试并协调退出；容器 supervisor 是不同所有权。存储失败不能静默初始化空实例。

队列、模型在途、输入缓冲、连接池和 sidecar 都有限且按进程计。使用代表性负载测量，不同时放大所有层，见[性能证据](../../PERFORMANCE.zh-CN.md)。

## 发布与验收

程序、静态 UI、原生 Bot 依赖来自同一源码/版本，保留许可并验证签名。新 schema 可能不支持降级，不暗示自动备份/回滚。

验证持久化、密钥、角色、模型 JSON/SSE、取消、过载、TLS 和目标平台打包。Windows 本地结果不代表 Linux/macOS。
