# 运行配置约定

[English](../../en/report/environment-and-runtime-config.md)

## 配置层次

已有进程环境变量优先于程序旁第一个 boost.env/Boost.env/.env、持久设置和默认值。加载器只补缺失值，工作目录下 .env 不是自动权威来源。

完整高级目录和启动/请求体/接入表统一见[配置参考](../../CONFIGURATION.zh-CN.md)，本文说明关系与实际行为，避免复制多套默认值。

## 持久设置

| 领域 | 存储与行为 |
| --- | --- |
| 监听 | 保存地址/bind mode 加显式环境，需重启 |
| 路由/模型默认 | 服务端设置与运行同步 |
| 资源限制 | gateway.resource_limits.v1，完整对象校验，对新准入生效 |
| 存储加密 | 凭据元数据/私有文件，重启转换 |
| 外观 | 设备或受支持 UI 设置，不改变权限 |
| 更新来源 | 构建时信任锚，不能运行覆盖 |

通用环境编辑器不能设置数据库/密钥/RPC 等启动凭据；保留网关及 worker 字段由专用控件管理。值冲突时显示有效来源与重启要求。

## 代理与 worker

单个 HTTP/SOCKS 可直接使用，多节点和受管原生协议需要兼容 sing-box。优先本地发现，显式更新/下载验证功能和配置；绑定来源失败不能静默直连模型。

推理在途/速率、管理队列、存储连接、HTTP worker 和 FastAPI 分开预算。放大一层可能只把争用移到下一层，保留存储余量并先测代表性负载。

## 日志与隐私

Trace 输入队列默认 4096、有效范围 1–65536，零不恢复无限队列。正文预览默认关闭，只在明确隔离诊断时启用。key、Cookie、启动 URL 和供应商凭据不进入公开导出。

## 排障与部署

修改环境文件需确认程序目录并重启；运行设置可能被显式环境变量遮蔽。容器内 Service/Web 必须共享一致数据和密钥来源。参见[构建](../../BUILDING.zh-CN.md)、[资源证据](../../PERFORMANCE.zh-CN.md)与[排障](最小排障手册.md)。
