# 后台任务账号准入

[English](../../en/report/background-task-account-skip-notes.md)

## 任务过滤

| 任务 | 准入条件 | 实现 |
| --- | --- | --- |
| 用量轮询 | 排除停用及账号/工作区终止、地区刷新受阻状态 | [批次选择](../../../backend/service/src/usage/refresh/batch.rs) |
| 网关保活 | 仅 active 且可用于网关的候选 | [账号候选](../../../backend/core/src/storage/accounts.rs) |
| Token 刷新 | refresh token 非空，且未因终止/地区原因暂停 | [Token 选择](../../../backend/core/src/storage/tokens.rs) |

不同任务处理的账号集合不同。仅 access token 的账号可能可推理，但不具备自动刷新条件。

## 排障

刷新失败可能到下次上游刷新才被发现。保活或轮询无动作可能表示候选为空，不代表调度器停止；先检查账号状态、最近错误、任务设置及当前批次，再调整 worker。

修正代理或地区问题后按既有恢复流程显式恢复账号，不能为增加吞吐自动重新启用被封禁/终止的账号。来源、模型权限和配额继续生效。

记录当前版本及脱敏状态，避免依赖容易失效的源码行号。
