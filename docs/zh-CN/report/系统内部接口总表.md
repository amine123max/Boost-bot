# 内部接口与传输约定

[English](../../en/report/system-internal-interface-inventory.md) · [系统架构](../../../ARCHITECTURE.zh-CN.md)

方法名称由服务端分发代码生成，参数与响应以类型化前端封装和 Rust 类型为准。此表是内部协作参考，不是允许绕过会话、角色或归属的公共 API。

## 传输与身份

| 入口 | 约定 |
| --- | --- |
| Tauri IPC | 使用集中 invoke/invokeFirst，服务地址通过 withAddr；原生命令按注册表提供 |
| Web POST /api/rpc | Boost Web 校验会话，推导 actor 后转发到内部 RPC |
| Service POST /rpc | 内部 RPC 凭据与可信 actor；不能暴露凭据给普通客户端 |
| 模型 /v1/ | 平台 key、模型权限、配额与计量，独立于管理 RPC |

请求使用 JSON-RPC 方法名；前端 underscore 命令与 camelCase/斜线方法映射必须同步。新增或重命名时同时修改实现、桌面注册、Web 映射和前端类型。

## 调度与错误语义

调度策略由显式 rpc_policy 分类，不以名称猜测只读。写任务全局 6 执行、最多 256 等待，每资源最多 32 等待；读通道最多 32 执行，含等待共 96 个，排队上限 2 秒。跨资源及未知方法使用全局屏障。排队超时表示未执行；开始后的断连不表示回滚。写请求禁止代理自动重放。
