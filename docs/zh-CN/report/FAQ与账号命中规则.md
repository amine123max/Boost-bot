# 路由与运行 FAQ

[English](../../en/report/faq-and-account-routing-rules.md)

## 来源选择

| 策略 | 含义 |
| --- | --- |
| 有序 | 按配置顺序尝试合格候选，失败时可继续后续来源 |
| 均衡 | 在 key/模型维度轮转，仍受明确健康策略限制 |
| 额度优先 | 按配置的剩余窗口策略选择合格来源 |
| 手动/来源绑定 | 限定在有权限的来源与映射内 |

sort 较小不保证命中。停用、缺凭据、模型不匹配、额度、冷却、熔断或在途限制都可能排除来源。

原生会话锚点优先于不相关的请求体缓存 key。账号切换可能需要新上游线程代次，不能复用不兼容的状态。

## 常见问题

| 问题 | 排查 |
| --- | --- |
| OAuth 回调不可用 | 监听端口及受支持的手动完成流程 |
| 上游 challenge/地区拒绝 | 账号授权状态、配置出口与提供商响应 |
| 系统代理拦截 loopback | 按部署网络策略排除本机回环 |
| 独立服务不可写 | 持久目录和密钥文件权限 |
| 模型来源错误 | 检查映射，聚合发现不授予账号池能力 |
| 临时容量拒绝 | 检查 Retry-After、活跃/等待预算，不能同时放大所有层 |

不再推荐已移除的兼容开关，也不把未来会话行为描述为当前实现。
