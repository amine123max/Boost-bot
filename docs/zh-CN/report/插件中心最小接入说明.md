# 插件接入检查

[English](../../en/report/plugin-center-minimal-integration.md)

## 接入决策

| 领域 | 决定 |
| --- | --- |
| 市场 | 内置或明确可信的 private/custom 来源 |
| 清单 | 稳定 ID、支持版本/运行时和脚本来源 |
| 能力 | 最小明确权限 |
| 任务 | 有效入口、计划、间隔和初始启用 |
| 运维 | 更新/停用/卸载和脱敏日志 |

遵循[完整约定](插件中心对接与接口清单.md)。目录为数组或带 items 数组对象，不以伪代码冒充可运行插件，也不借隐藏管理员权限令清单表面可用。

## 验证顺序

1. 解析并拒绝无效/不支持元数据。
2. 通过类型化应用路径安装。
3. 逐项验证请求能力，确认未授权能力失败。
4. 手动运行一次任务，检查真实结果和日志。
5. 修改计划/启用状态，重启后验证。
6. 停用/卸载且不触碰无关数据。

Rhai 能力和传输授权分别治理，生产网络/清理插件需隔离数据和明确审查的来源。
