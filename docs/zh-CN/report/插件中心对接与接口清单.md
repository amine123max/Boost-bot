# 插件架构与约定

[English](../../en/report/plugin-center-integration-and-interfaces.md)

## 层次与权限

插件中心区分市场分发、安装状态、计划任务和 Rhai 执行。builtin/private/custom 三种模式中，builtin 忽略远端源，private/custom 使用管理员设置的目录 URL。

| 字段 | 类型/默认 | 约定 |
| --- | --- | --- |
| id | 必填字符串 | 稳定唯一身份 |
| name/version | 字符串，回退 ID / 0.0.0 | 展示和更新元数据 |
| scriptBody/scriptUrl | 至少一种来源 | 内联或远端 Rhai |
| permissions | 字符串数组 | 明确请求的能力 |
| tasks | 任务数组 | 入口、调度、间隔、启用 |
| manifestVersion/runtimeKind | 1 / rhai | 支持的清单/运行时 |
| 分类、标签、主页 | 可选 | 不授予权限 |

目录支持数组或 items 对象，安装/更新验证脚本与清单。友好名称或市场收录不授予权限，全局管理保持高权限。

## 执行边界

只暴露注册能力；读设置、网络和账号清理分别需要权限。日志必须脱敏。Rhai 运行边界不等于其他工具的完整 OS 隔离。

任务持久化调度/配置并生成有界诊断日志。手动、重试与周期执行明确副作用，避免重复清理/计费；停用/卸载不删除无关用户数据。

## 验收

验证不支持清单、不可达脚本、权限拒绝、计划修改、手动运行、停用/卸载及日志脱敏。空自定义源保持为空，不切到未指定市场。
