# 排障流程

[English](../../en/report/minimal-troubleshooting-guide.md)

## 定位失败边界

| 现象 | 优先检查 |
| --- | --- |
| 无法打开界面 | 进程、监听、静态资源、Web 会话和代理路由 |
| 存储启动失败 | 密钥来源、权限、锁占用、空间和完整性 |
| 未授权 | 区分 Web 会话、内部 RPC 凭据和平台 key |
| 模型不可用 | 目录、来源映射、身份权限和来源状态 |
| 429 | 区分临时速率/并发拒绝与累计额度耗尽 |
| 流停顿 | 上游首字节、缓冲、空闲期限和断连清理 |
| 上游反复失败 | 尝试链、冷却/熔断和剩余候选 |

按[架构](../../../ARCHITECTURE.zh-CN.md)判断哪个进程负责，修改有效运行配置，而不是无关的浏览器偏好。

## 证据

关联服务 trace、路径、模型/来源 ID、状态和耗时。保留脱敏错误摘要及测试条件，不把完整提示词、响应、凭据或私有路径发到公开 Issue。密钥不可用时不能重新初始化数据库。

## 恢复

仅在错误明确允许时安全重试。管理执行超时可能结果未知，先查询再提交变更。熔断用于减轻压力，提高并发不能修复上游。

使用相同复现和相关运行模式验证。参见[配置](../../CONFIGURATION.zh-CN.md)、[路由 FAQ](FAQ与账号命中规则.md)及[验证](../../../TESTING.zh-CN.md)。
