# 账号模式与额度分发锁定

[English](../../en/report/account-billing-mode-locks.md) · [安全](../../../SECURITY.zh-CN.md)

## 状态边界

登录模式和额度分发改变身份与账务，不是外观偏好。无登录/共享密码不能像账号模式一样表达成员归属；额度分发依赖账号模式及有效成员归属。

| 切换 | 规则 |
| --- | --- |
| none/password → accounts | 管理员显式操作 |
| accounts → none/password | 正式账号计费状态锁定后拒绝 |
| 分发关闭 → 开启 | 需要 accounts |
| 分发开启 → 关闭 | 分发锁定后拒绝 |

共享密码模式还需已配置访问密码。即使绕过界面，后端也执行限制。

## 锁定依据

成员、key 归属、非零/冻结钱包、钱包流水、模型组成员或请求扣费均可形成正式使用证据。服务返回状态及具体原因码，界面禁用危险切换并说明约束。

## 归属与计费

分发 key 归属有效成员，停用用户、停用钱包及余额不足按业务策略拒绝。模型组控制访问和倍率，计费模型信息可优先于通用兜底规则。

管理员身份不作为成员钱包捷径。遗留项目字段不授权在 UI 新增按项目分发模式。

## 维护与验收

恢复是独立高权限维护流程，须说明影响、授权及记录；不自动备份、重置模式或删除历史流水，普通 Web 控件不能解除已锁边界。

验证全部允许/禁止切换、直调 RPC、归属/模型/钱包隔离及原因展示。实现依据：[模式检查](../../../backend/service/src/auth/app_manager.rs)、[类型与 UI](../../../frontend/src/lib/api/billing-mode-lock.ts)。
