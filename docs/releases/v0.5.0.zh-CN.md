# Boost 0.5.0

[English](v0.5.0.md) · [历史发行](https://github.com/amine123max/Boost-bot/releases/tag/v0.5.0)

首个稳定桌面版本整合账号管理、OpenAI 兼容网关与受管 Bot 工作台。本文记录历史能力；当前配置和安全行为请参阅[构建指南](../BUILDING.zh-CN.md)。

## 能力范围

| 组件 | 当时交付的能力 |
| --- | --- |
| 账号 | 导入、授权状态、可用性、用量窗口与路由偏好 |
| 网关 | Responses、Chat Completions、JSON/SSE、工具调用、模型映射与聚合上游 |
| 权限与用量 | 平台密钥、模型权限、配额、价格、请求日志与统计 |
| Bot | 对话、记忆、任务、审批、渠道和工具权限 |
| 桌面 | 托盘、主题、悬浮监测、本机任务日志观察及用户控制的更新 |
| 部署 | 桌面，以及源码构建的 Service/Web 与 Docker |

网关与渠道能力依赖真实上游凭据、配额和宿主权限。历史监测使用实际输出 Token 采样；来源没有报告进度时保持不定进度。

## 安装附件

| 平台 | 历史文件 |
| --- | --- |
| Windows x64 免安装 | Boost_0.5.0_x64.exe |
| Windows x64 安装 | Boost_0.5.0_x64-setup.exe |
| macOS Apple Silicon | Boost_0.5.0_aarch64.dmg |

从历史 Release 下载并核对 SHA-256。Windows 需要 WebView2；macOS 打开 DMG 后将 Boost.app 拖入应用程序，本版本未完成 Apple 公证。源码压缩包不能直接启动桌面应用。当时没有 Intel Mac、Linux 桌面和 Windows ARM64 安装附件。

升级前退出运行中的实例。免安装版在首次启动准备内嵌 Node/Bot 运行时；设置、数据库、日志和缓存保存在用户 .boost 目录，删除程序不会移除这些数据。

## 首次接入

启动 Boost，添加账号或聚合上游，配置模型并创建平台 API 密钥。本地兼容客户端使用 http://localhost:12580/v1 与该平台密钥；管理 Web 使用 http://localhost:12000。首次调用后检查请求日志。提供商密钥用于上游配置，不用于客户端配置。
