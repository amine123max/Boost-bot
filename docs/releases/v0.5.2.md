# Boost 0.5.2

[简体中文](v0.5.2.zh-CN.md) · [Downloads](https://github.com/amine123max/Boost-bot/releases/tag/v0.5.2)

- Bot web chat streams reply text as it arrives and restores history and active replies automatically after a refresh or disconnect. Reconnecting does not submit the message again.
- The Bot conversation layer shares reply rules and context across model paths. Tools continue to run through the bundled DSH process under the active user's permissions.
- Messages queue per conversation. Explicit task commands open a separate task list; task results and structured questions update their own conversation. WeChat and Feishu accounts stay scoped to their bound Bot.
- The Boost toolbar preserves the last usage data when the local management service is busy and retries the read in the background.
- Adjusted the macOS settings dialog and the floating window's top-edge snapping. Manual verification across Mac displays and scale settings remains pending.

Downloads include the Windows x64 portable EXE and installer, and the macOS Apple Silicon DMG. Verify downloads with `SHA256SUMS.txt`.
