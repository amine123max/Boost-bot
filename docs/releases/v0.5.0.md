# Boost 0.5.0 正式版

Boost 将 AI 账号管理、兼容 OpenAI 的 API 网关与 Bot 工作台整合在同一应用中。本次正式发布提供 **Windows x64 单文件免安装版、Windows x64 安装版，以及 macOS Apple Silicon 安装包**。

## 核心功能

- **账号与授权管理**：集中导入与管理账号，检查授权状态、账号可用性和额度窗口，配置路由偏好。
- **统一 API 网关**：支持 OpenAI 风格的 Responses、Chat Completions、流式响应和工具调用，提供模型映射与聚合上游配置。实际可用协议、模型和工具能力取决于所接入的上游。
- **密钥、模型与用量管理**：管理平台 API 密钥、访问权限、配额与模型定价，通过请求日志和用量统计定位调用问题。
- **内置 Bot 工作台**：提供对话、记忆、任务、审批、消息渠道及工具权限控制；桌面发行包包含配套 Node.js 和 Bot 运行时。
- **桌面体验**：支持系统托盘、明暗主题与强调色；关闭窗口可直接最小化或退出。最小化显示可拖动的紧凑悬浮窗，悬停和点击均不展开，共用主窗口服务。首次创建悬浮窗在后台执行，避免 Windows WebView2 同步创建导致界面卡死。更新来自 `amine123max/Boost-bot`，由用户决定下载和安装。
- **紧凑悬浮窗**：顶部横向、侧边竖向吸附，双击返回主窗口；独立选择余量、任务进度、TPS、上行、下行和内存，显示项即时同步并记忆。
- **本机任务监测**：支持内置 Bot 与本机 Codex、Claude Code、DeepSeek Harness 日志；有明确进度报告时显示估计百分比，没有报告时保持不定进度。TPS 使用实际输出 token 采样，不由网络字节推算。
- **统一用户存储**：桌面应用数据、日志、运行时和更新统一位于 `~/.boost`，Windows/Linux 界面缓存使用 `.boost/cache/webview`。首次升级迁移旧目录，SQLite 快照包含 WAL 中的账号、用量和 Bot 对话；已有新目录文件不会覆盖。详细布局见[用户存储说明](../BUILDING.md#desktop-user-storage--桌面用户存储)。
- **设置与导航**：齿轮弹窗配置、说明图标、GitHub 入口与侧栏搜索；顶部标题 22px 与品牌对齐，导航 18px、字间距增加 0.5px。
- **自托管能力**：同一项目支持桌面应用和 Service + Web / Docker 部署；本次附件为桌面发行包，自托管请参阅构建与部署文档。

## 安装说明

### Windows 免安装版

1. 下载 `Boost_0.5.0_x64.exe`，放到准备长期使用的位置后双击启动。
2. 首次启动会将内嵌 Bot 运行时准备到应用缓存目录，可能比后续启动耗时更长；请等待初始化完成，并确保用户数据与缓存目录可写且有足够磁盘空间。
3. 免安装指无需安装向导；账号、设置和运行时缓存保存在用户的 `.boost` 目录，删除 EXE 不会自动清理这些数据。

### Windows 安装版

1. 下载并运行 `Boost_0.5.0_x64-setup.exe`。
2. 按安装向导完成安装，再从开始菜单或快捷方式启动 Boost。
3. Windows 桌面界面依赖 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。若启动时提示缺少运行时，请安装微软官方版本后重试。

### macOS 安装版

1. 确认设备使用 Apple Silicon（M 系列芯片），下载并打开 `Boost_0.5.0_aarch64.dmg`。
2. 将 `Boost.app` 拖入“应用程序”，然后从“应用程序”启动。
3. 本版本尚未完成 Apple Developer ID 公证。若 Gatekeeper 阻止启动，确认文件来自本仓库并核对 SHA-256 后，可在“系统设置 → 隐私与安全性”中允许打开。
4. 若仍因下载隔离属性提示“已损坏”或无法打开，可仅对已核验的应用在终端执行以下命令，再重新启动：

   ```bash
   xattr -dr com.apple.quarantine /Applications/Boost.app
   ```

## 首次使用与客户端接入

1. 启动 Boost，在界面中确认本地服务已启动；若未启动，点击“启动服务”。
2. 在“账号管理”添加 / 导入账号并完成授权，刷新用量、检查可用状态；也可在“聚合 API”配置上游地址和上游密钥。
3. 在“模型”中导入或选择可用模型，检查调用来源与路由配置。
4. 在“密钥”创建 Boost 平台密钥。客户端应填写该平台密钥，上游提供商密钥用于上游连接配置。
5. 在支持 OpenAI 兼容接口的客户端中填写以下配置，发送一次请求后到 Boost“日志”检查结果。

| 客户端配置项 | 桌面本地默认值 |
| --- | --- |
| Base URL | `http://localhost:12580/v1` |
| API Key | 在 Boost 中创建的平台密钥 |
| Model | Boost 模型目录中已配置路由的实际模型 ID |

修改服务地址或端口后，请同步修改客户端配置。界面“密钥 → 配置方法”可复制当前配置。自托管 Web / Docker 模式使用对外 Web 地址追加 `/v1`，例如 `http://服务器地址:12000/v1`；浏览器管理入口为 `http://服务器地址:12000`。

使用内置智能体时，进入 Bot 工作台，完成模型 / 提供商配置后开始对话；使用工具、任务或消息渠道前，请配置相应权限与凭据。

## 兼容性与已知限制

- **系统与架构**：Windows 包面向 x64 设备，建议使用 Windows 11；Windows 10 x64 需具备可用的 WebView2 运行环境。macOS 包仅面向 Apple Silicon；旧版系统及其他架构的运行兼容性未在本次发布中全面验证。
- **运行时**：三个桌面包均包含 Node.js 与 Bot 运行时，正常使用无需另装 Node.js、pnpm、Rust 或开发工具。Windows 仍需具备 WebView2。
- **签名提示**：本次未提供 Windows 代码签名或 macOS Developer ID 公证，Windows SmartScreen / macOS Gatekeeper 可能提示来源验证。请核对仓库、文件名与校验值后再决定运行。
- **网络与代理**：账号授权、模型请求和外部渠道需要访问对应服务。本地代理应允许 `localhost` / `127.0.0.1` 直连；遇到连接问题时检查本地端口占用、代理和防火墙设置。
- **服务能力**：软件包不包含第三方账号、API 额度或上游订阅；可用模型、流式响应和工具调用受上游权限及协议支持情况影响。
- **计费统计**：模型价格与用量统计用于管理和估算，实际费用以上游提供商账单为准。
- **升级使用**：更换版本前退出正在运行的 Boost 和托盘进程。免安装版与安装版可能使用相同的用户数据目录，建议选择一种方式日常运行。

## 校验与反馈

下载后可使用本次附件 `SHA256SUMS.txt` 核对 SHA-256。

Windows PowerShell：

```powershell
Get-FileHash .\Boost_0.5.0_x64.exe -Algorithm SHA256
# 安装版请替换为 Boost_0.5.0_x64-setup.exe
```

macOS 终端：

```bash
shasum -a 256 Boost_0.5.0_aarch64.dmg
```
