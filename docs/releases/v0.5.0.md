Boost 0.5.0 将 AI 账号管理、兼容 OpenAI 的 API 网关与 Bot 工作区整合在同一桌面应用中。本次发布提供 Windows x64 桌面免安装版、Windows 安装版及 macOS Apple Silicon 安装包。

## 核心功能

- **账号与授权管理**：集中管理账号导入、授权状态、可用性检查、使用窗口与路由偏好。
- **统一 API 网关**：支持 Responses、Chat Completions、流式响应及工具调用，并提供模型映射和聚合上游配置。实际协议能力取决于所选上游与模型。
- **密钥与用量管理**：提供 API 密钥归属、访问控制、配额、模型定价及请求日志，便于配置与排查调用问题。
- **内置 Bot 工作区**：支持对话、记忆、任务、审批、消息渠道和权限控制；发行包包含配套 Node.js 与 Bot 运行时。
- **桌面体验**：提供托盘控制、明暗主题、强调色和版本更新能力。

## 使用说明

**Windows 免安装版**是完整的桌面 EXE。Bot 运行时嵌入程序，首次启动会自动准备到应用缓存目录，因此首次启动可能比后续启动耗时更长。账号数据和应用设置保存在系统应用数据目录中，无需在程序旁手动维护运行时文件。

Windows 桌面界面依赖 Microsoft Edge WebView2 Runtime；若系统尚未安装，请先安装微软官方运行时。所有桌面发行包均包含 Node.js，无需另外配置 Node.js 开发环境。

本次发行包未提供 Windows 代码签名或 macOS Developer ID 公证，系统可能显示来源验证提示。请从本仓库 Release 下载，并核对发布资产中的 SHA-256 校验信息后运行。
