# Boost 0.5.2

[English](v0.5.2.md) · [发行附件](https://github.com/amine123max/Boost-bot/releases/tag/v0.5.2)

- Bot 网页回复逐段显示。刷新或断线后自动恢复历史和正在生成的回复，恢复时不会重复发送消息。
- Bot 原生对话层统一管理回复规则和会话上下文。工具继续由随包 DSH 进程在当前用户权限下隔离执行。
- 消息按会话排队；显式任务命令打开独立的任务清单，任务结果和结构化提问同步到所属会话。微信和飞书账号各自归属绑定的 Bot。
- 顶栏刷新和切页时，本机管理服务短时繁忙会保留已有数据并重试。只读请求支持 32 路并发、最多接纳 96 个、排队最多 2 秒。
- 悬浮文件名可预览差异，点击可在对话内展开并保持打开。顶栏显示当前任务名称和状态，右侧按任务、渠道、宿主工具和历史分组。
- 受信任的 Bot 可连接本机 MCP 服务，在支持的宿主上经审批操作电脑。系统管理员可查看本机进程和 Agent 状态。Windows 包内置 Whisper Tiny 语音转写，其他平台可另行部署。
- 调整 macOS 设置弹窗与悬浮窗贴顶行为。不同显示器和缩放比例下的原生交互仍待手动验收。

提供 Windows x64 免安装版和安装版，以及 macOS Apple Silicon DMG。可用 `SHA256SUMS.txt` 核对下载。
