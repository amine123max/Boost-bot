# Boost 0.5.1

本次更新完善 Bot 的任务与协作体验，修正悬浮窗实时数据，并统一近期管理界面的交互。

## 更新内容

- **Bot 工作台**：Vue 3 + TypeScript 前端与后端、共享代码、资源目录分离；保留原有 Boost 品牌和三栏布局。智能体下可展开网页、飞书、微信等真实渠道会话。
- **计划与处理过程**：右侧展示当前会话计划和后台任务卡片，支持步骤折叠、详情和导出；会话正文显示无外框的计划概览，实际模型摘要和工具记录可展开查看。任务卡片增加上下间距。
- **多 Bot 协作**：改进交接文本与文件保真、失败重试和请求去重；直接模型请求支持 Chat Completions、Responses、Messages。可选 FastAPI 服务入口保留 Boost 鉴权与 nginx 部署链路，桌面端仍内置受管 Node 引擎。
- **悬浮窗**：组件库采用无边框弹簧轮播，可拖入底部真实尺寸横条装配与重排。黑／白预览使用同样的左右箭头、底部圆点和弹簧切换，外观同步到实际悬浮窗。进度环保留头像，TPS 始终显示圆环，上下行读数紧凑排列。
- **实时状态**：本机任务与 Bot 独立采样，支持成功的任务计划更新；修复直接对话未进入监测的问题。TPS 仅使用实际 token 采样，过期清空，未知进度保持不定状态。
- **额度重置**：采用与退出确认一致的紧凑专用窗口；展示账号与剩余次数，防止重复提交，失败留窗并支持显式重试。
- **管理体验**：操作独立显示等待状态；服务共用有界管理 RPC 队列，减少重复操作与写请求重放。更新用量卡片、前日对比、折叠明细，以及中文／英文／数字的独立字体设置。
- **工程维护**：清理独立测试目录及废弃原型／验证脚本，修正构建、运行时打包和发布路径。保留源码内的 Rust 单元测试与实际运行验收。
