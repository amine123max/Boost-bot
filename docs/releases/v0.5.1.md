# Boost 0.5.1

本次更新在 0.5.1 中同步近期 Bot、独立聚合来源、任务步骤与界面审查修正，并更新 README 的实际界面截图。侧栏搜索框上下留白保持一致。

## 更新内容

- **Bot 工作台**：Vue 3 + TypeScript 前端与后端、共享代码、资源目录分离；保留原有 Boost 品牌和主布局。智能体下只展开飞书、微信等已有消息的外部渠道，网页对话通过Bot本身进入；支持单Bot增删改和渠道文件分析／授权推送。
- **计划与处理过程**：删除会话中的重复处理概览与下载／放大入口。真实任务在处理过程内按步骤展示，进行中转圈、完成勾选、失败明确；模型重试收进所属请求详情，不伪造任务完成或推理内容。
- **会话与对齐**：回复气泡使用主题底色，时间与复制按钮置于气泡外，用户气泡保持原样。Boost各管理页顶部操作与侧栏搜索框对齐，分类标签与操作同行，搜索框上下留白一致。
- **独立模型来源**：每个Bot可选择号池或指定聚合API，按当前账号授权筛选目录；模型、辅助请求、代理及渠道沿同一来源路由。密钥停用／越权时明确失败，不静默切换；凭据不进入浏览器。
- **模板更新保护**：专用Bot更新模板保留已选模型来源、辅助模型及用户设置，停止代理期间新保存的配置也继续生效；模板不能自动扩大权限，已撤销的能力会收回。
- **设置与外观**：全局左侧导航连接同一设置页，单Bot使用绑定当前目标的弹窗；独立分区横幅从首屏固定，顶部横线贯穿，正文分隔保持对齐。统一紧凑标题、主题化模型下拉与厂商SVG，修复浅色账号标签。权限菜单点击即保存当前Bot。
- **自然过渡**：页面、弹窗及自定义菜单使用无缩放、无反冲的阻尼过渡，减少动画可关闭；说明提示鼠标移开即淡出。隐藏可见滚动条，保留滚轮、触控与键盘访问。Boost顶部压缩留白并采用独立灰色，品牌／头像大小不变。
- **多 Bot 协作**：改进交接文本与文件保真、失败重试和请求去重；直接模型请求支持 Chat Completions、Responses、Messages。可选 FastAPI 服务入口保留 Boost 鉴权与 nginx 部署链路，桌面端仍内置受管 Node 引擎。
- **悬浮窗**：组件库采用无边框弹簧轮播，可拖入底部真实尺寸横条装配与重排。黑／白预览使用同样的左右箭头、底部圆点和弹簧切换，外观同步到实际悬浮窗。进度环保留头像，TPS 始终显示圆环，上下行读数紧凑排列。
- **实时状态**：本机任务与Bot独立采样，支持新版Codex日志计数并去重；TPS使用真实输出Token与耗时，必要时明确显示请求均速，未知进度不编造百分比。用量较前日支持增长、下降、持平与缺少样本。
- **额度重置**：采用与退出确认一致的紧凑专用窗口；展示账号与剩余次数，防止重复提交，失败留窗并支持显式重试。
- **管理体验**：操作独立显示等待状态；服务共用有界管理 RPC 队列，减少重复操作与写请求重放。更新用量卡片、前日对比、折叠明细，以及中文／英文／数字的独立字体设置。
- **工程维护**：清理独立测试目录及废弃原型／验证脚本，修正构建、运行时打包和发布路径。保留源码内的 Rust 单元测试与实际运行验收。

## English

This refreshed 0.5.1 release adds per-Bot account-pool/aggregate-source bindings, authorized source-specific models, channel document analysis and improved collaboration. Processing steps now stay inside one expandable trace, with running rings, completed checks and nested retries. Shared compact dialogs, independent settings banners, local provider SVGs, light-theme tag colors and non-oscillating transitions are included. README screenshots reflect the updated interface. Live token sampling, signed daily usage comparisons and the floating monitor remain available without fabricated metrics.

Choose the Windows x64 portable EXE or installer, or the Apple Silicon DMG. Quit the running app before upgrading, retain the existing `~/.boost` data directory, and verify the download with `SHA256SUMS.txt`. Real providers and messaging channels still require valid credentials and host permissions.
