# Boost 0.5.1

本次更新在 0.5.1 中同步近期 Bot、独立聚合来源、任务步骤与界面审查修正，并更新 README 的实际界面截图。侧栏搜索框上下留白保持一致。

## 更新内容

- **上新功能页面**：点击内置智能体打开对应功能预览，首次点击“对话与审批”后才创建实例，重复操作复用已有实例；处理时钟按整行垂直居中，刷新入口实际更新当前数据。
- **渠道与设备**：沿用“添加渠道”弹窗，支持微信、飞书、Telegram、Slack、Discord、钉钉和 QQ，多设备／账号分别命名、启停与设置默认智能体；微信和飞书扫码，其他渠道使用官方凭据。钉钉采用 Stream，QQ 采用签名 Webhook 和现有 nginx 代理。工具授权与聊天账号不重复展示；具体平台连接仍需有效凭据与部署配置。
- **迁移后会话恢复**：恢复代理前校正原工作区路径，保留已有会话与子目录，避免沙箱搬迁后仍引用旧工作目录。
- **运行时复用与空间控制**：便携版运行时归档固定元数据，文件内容相同的重新构建复用原缓存；全部 Bot 共用同一份 Node 和运行依赖。新版本准备成功后清理未使用的旧运行时，保留仍被运行进程引用的版本；不会删除会话、凭据、数据库或沙箱。清理失败不阻断启动。
- **本轮细节修正**：移除Bot外层大环加载页，保留内层紧凑加载与错误重试；左侧上新仅浏览，明确添加才创建；侧栏使用无按钮外框的展开／收起SVG，渠道已连接显示绿色底色。模型计费搜索框不挤压、不裁切；四张智能体卡片大小一致，自定义卡片采用虚线Bot头像、名称“自定义”和“＋自定义”按钮，说明收进名称后的感叹号。
- **追加审查修正**：侧栏切换按钮回到分隔线上，透明圆形点击区，仅邻近悬浮／键盘聚焦时显示；收缩图标保留短竖线。自定义按钮使用灰色；权限选项压缩留白并保留项间距，勾选图标整行居中。Bot数据位置可保存迁移目标，重启时在数据库和渠道打开之前搬迁，保留历史路径；长路径可换行，桌面版“显示目录”直接定位。
- **TokenRhythm价格**：三款已接入模型支持官网报价同步，使用同步当天最新可用的Frankfurter/ECB人民币兑美元参考汇率；保留汇率日期，缓存读取单价独立匹配，异常保留旧值与用户自定义价格。
- **Bot 工作台**：Vue 3 + TypeScript 前端与后端、共享代码、资源目录分离；保留原有 Boost 品牌和主布局。智能体下只展开飞书、微信等已有消息的外部渠道，网页对话通过Bot本身进入；支持单Bot增删改和渠道文件分析／授权推送。
- **计划与处理过程**：删除会话中的重复处理概览与下载／放大入口。真实任务在处理过程内按步骤展示，进行中转圈、完成勾选、失败明确；模型重试收进所属请求详情，不伪造任务完成或推理内容。
- **会话与对齐**：网页版直接对话回复不加气泡；飞书、微信等渠道Bot回复使用跟随主题主色的柔和底色，时间与复制按钮置于气泡外，用户气泡保持原样。Boost各管理页顶部操作与侧栏搜索框对齐，分类标签与操作同行，搜索框上下留白一致。侧栏切换按钮支持收起，图标与无框搜索居中，动态品牌保留。
- **沙箱目录**：可选择其他磁盘或文件夹，在Boost内按工作台与智能体整理目录；重启前不影响当前任务，启动时迁移、保留历史路径兼容链接，并检查目标冲突与文件访问边界。
- **上下文占用**：优先使用已知模型容量或代理执行窗口，未提供时默认128K；按下方分类颜色分段，分类与条形数值一致，未分类差额独立显示，修复空轨道并增加上下间距。
- **紧凑卡片与厂商图标**：智能体卡片头像左置、名称与按钮右置，压缩横向留白；协议筛选使用正确的OpenAI／Claude／Gemini SVG，Bot与Boost共用主题色板。
- **独立模型来源**：每个Bot可选择号池或指定聚合API，按当前账号授权筛选目录；模型、辅助请求、代理及渠道沿同一来源路由。密钥停用／越权时明确失败，不静默切换；凭据不进入浏览器。
- **聚合协议可靠性**：修复聚合请求转发压缩偏好后，压缩JSON经过Responses转换却保留gzip标头的问题。上游显式协商identity，避免HTTP200但流式正文解码失败或内容丢失；JSON、SSE及工具往返均经过回归。
- **模板更新保护**：专用Bot更新模板保留已选模型来源、辅助模型及用户设置，停止代理期间新保存的配置也继续生效；模板不能自动扩大权限，已撤销的能力会收回。
- **设置与外观**：全局左侧导航连接同一设置页，单Bot使用绑定当前目标的弹窗；独立分区横幅从首屏固定，顶部横线贯穿，正文分隔保持对齐。统一紧凑标题、主题化模型下拉与厂商SVG，修复浅色账号标签。权限菜单点击即保存当前Bot。
- **自然过渡**：页面、弹窗及自定义菜单使用无缩放、无反冲的阻尼过渡，减少动画可关闭；说明提示鼠标移开即淡出。隐藏可见滚动条，保留滚轮、触控与键盘访问。Boost顶部压缩留白并采用独立灰色，品牌／头像大小不变。
- **多 Bot 协作**：改进交接文本与文件保真、失败重试和请求去重；直接模型请求支持 Chat Completions、Responses、Messages。可选 FastAPI 服务入口保留 Boost 鉴权与 nginx 部署链路，桌面端仍内置受管 Node 引擎。
- **悬浮窗**：组件库采用无边框弹簧轮播，可拖入底部真实尺寸横条装配与重排。黑／白预览使用同样的左右箭头、底部圆点和弹簧切换，外观同步到实际悬浮窗。进度环保留头像，TPS 始终显示圆环，上下行读数紧凑排列。
- **实时状态**：本机任务与Bot独立采样，支持新版Codex日志计数并去重；TPS使用真实输出Token与耗时，上游仅在请求结束返回用量时显示请求均速。任务进度优先真实上报，缺失时以不均匀速率在10分钟累计到80%并等待完成，成功才到100%；等待输入暂停，失败不补满。悬浮窗只显示累积变色的进度环与头像，不增加进度文字、数值或来源标注。侧栏展开／收起使用无反冲弹簧过渡。用量较前日支持增长、下降、持平与缺少样本。
- **额度重置**：采用与退出确认一致的紧凑专用窗口；展示账号与剩余次数，防止重复提交，失败留窗并支持显式重试。
- **管理体验**：操作独立显示等待状态；服务共用有界管理 RPC 队列，减少重复操作与写请求重放。更新用量卡片、前日对比、折叠明细，以及中文／英文／数字的独立字体设置。
- **工程维护**：清理独立测试目录及废弃原型／验证脚本，修正构建、运行时打包和发布路径。保留源码内的 Rust 单元测试与实际运行验收。

## English

This refreshed 0.5.1 release adds per-Bot account-pool/aggregate-source bindings, authorized source-specific models, channel document analysis and improved collaboration. Processing steps now stay inside one expandable trace, with running rings, completed checks and nested retries. Shared compact dialogs, independent settings banners, local provider SVGs, light-theme tag colors and non-oscillating transitions are included. README screenshots reflect the updated interface. Live token sampling uses reported usage; when upstream usage arrives only at completion, TPS represents the request average. Task progress prioritizes reported values and uses a capped ten-minute timer when absent; successful completion reaches 100%. The floating progress widget shows only the ring and avatar, without extra labels or percentage text.

Choose the Windows x64 portable EXE or installer, or the Apple Silicon DMG. Quit the running app before upgrading, retain the existing `~/.boost` data directory, and verify the download with `SHA256SUMS.txt`. Real providers and messaging channels still require valid credentials and host permissions.
