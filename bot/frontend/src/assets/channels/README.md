# Channel brand SVG sources

- WeChat, Telegram, Discord: [Simple Icons](https://github.com/simple-icons/simple-icons), CC0.
- Slack: [Simple Icons 14.15.0](https://github.com/simple-icons/simple-icons/tree/14.15.0), CC0.
- QQ: [Simple Icons 13.21.0](https://github.com/simple-icons/simple-icons/tree/13.21.0), CC0.
- DingTalk: [Ant Design Icons](https://github.com/ant-design/ant-design-icons/blob/master/packages/icons-svg/svg/outlined/dingding.svg), MIT, copyright Ant Design.
- Feishu: [AnyModelBot](https://github.com/modelflare-ai/AnyModelBot/blob/master/ui/assets/apps/feishu.svg), MIT, copyright the AnyModelBot contributors.

Monochrome sources inherit the theme foreground. Logos belong to their respective owners. SVG files are bundled locally; no remote icon requests are made at runtime.
