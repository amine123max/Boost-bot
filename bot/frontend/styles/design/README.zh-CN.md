# Bot 设计样式

[English](README.md) · [Bot 前端](../../../README.zh-CN.md)

此目录包含共享主题与表面样式。实际工作台位于 bot/frontend/src，以 Vue 单文件组件维护；构建将样式复制到运行时静态目录，保留既有 Bot 与沙箱资源 URL。

使用语义 token 支持深浅色，尊重减少动态偏好，将应用页面规则放入 app layer。状态颜色必须配可读文字。操作说明放在键盘可访问的悬停/聚焦提示，执行记录在消息内展开。

对话框、菜单和提示共用主应用运动及表面契约，不能用缩放改变容器尺寸或重放副作用。不得向产品界面暴露凭据、实现说明或虚构运行数据。

在受权的真实 Vue 工作台和专用预览中检查桌面、窄屏、键盘与主题切换。构建和运行验收见[验证说明](../../../../TESTING.zh-CN.md)。
