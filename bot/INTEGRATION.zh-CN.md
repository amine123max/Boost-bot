# 受管运行时集成

[English](INTEGRATION.md) · [Bot 概览](README.zh-CN.md) · [系统架构](../ARCHITECTURE.zh-CN.md)

## 所有权与启动

Rust 服务负责 actor、平台 key、来源 broker 租约、子进程生命周期和受权代理；Node 负责会话、智能体、任务、渠道、审批和工作目录工具。FastAPI/Nginx 是可选接入层。

受管宿主通过有界私有 stdin 记录接收数据路径、loopback 网关、有归属 key、启动令牌、身份权限和可选派生数据库密钥，秘密不放入命令行。Node 校验可信地址、登记脱敏值，并在打开状态前取得目录锁。

| 边界 | 约定 |
| --- | --- |
| Actor 范围 | 可信角色/用户的稳定摘要 |
| 启动令牌 | 宿主内部 HTTP 授权 |
| 平台 key | 经 Boost 执行模型权限、归属与计费 |
| 来源 broker | 服务端选择有权限的账号/聚合模型 |
| 数据库密钥 | 主密钥经 HMAC-SHA256 按身份独立派生 |
| 数据锁 | 拒绝并发占用与不安全迁移 |

未传密钥的独立明文模式保持兼容；受管加密模式在正常启动前转换并验证 Bot SQLite。工作文件、日志和任意输出不属于数据库加密。

## HTTP 与流式传输

Web 验证浏览器并推导 actor，Service 选择对应宿主；调用者不能指定内部身份。传输链保留请求/响应字节、query 和 SSE 格式；断连释放上游连接及准入预留。

可选 Python 网关仅指向固定可信 Boost Web，剥离内部 actor/RPC 头，限制活跃、等待和输入内存，不自动重放写请求。参见 [FastAPI](backend/api/README.zh-CN.md) 和 [Nginx](../nginx/README.zh-CN.md)。

## 模型与执行

Bot 只能绑定身份可见来源，目录发现不授予访问权限，映射保持账号池和聚合连接区分；工具权限独立于模型是否可用。

DSH 提供真实执行、工具与审批。界面区分结构化计划和历史活动，不能补造思考、审批、进度或完成事件。群协作保留成员关系与文件访问检查。

### 对话生命周期

受管对话关闭总回合和空闲截止时间，包括旧配置中的非零值；独立模式两项默认也为零。主动停止、提供商错误及单项工具/审批策略仍然生效。消息提交返回接收凭据，与 SSE 独立；补充消息可并入运行中的智能体回合，否则按会话顺序等待。浏览器断连后服务端继续执行。

历史重新生成更新原用户消息行，保留会话、消息 ID、时间和之前的上下文。服务端先停止并等待旧回复结束，移除当前分支此后的消息，再按保留上下文重建智能体执行会话。原文校验拒绝过期编辑；重新生成无法撤销已经发生的外部工具副作用。提交编号在凭据保留窗口内防止重复执行。

### AI 任务层级

对话、后台任务和定时运行共用服务端 AI 分析。授权辅助模型负责归纳，未配置时使用选定的主模型；最多六个大节点，每个最多五个子节点。后台下拉区域仅展示所属任务的层级、状态和进度，不另设会话计划卡片、AI 标题、节点计数或详情按钮；工具记录在会话处理区和任务管理中查看。处理区执行中按实际回合起始时间显示“已处理 xx 秒”，结束后显示“已完成”。未执行的任务和规则可提前规划；每次实际运行独立绑定证据和缓存。完成状态必须有成功证据支持；百分比表示已归入记录的完成比，未知进度留空。

分析限制为两路执行、八个等待、25 秒截止；合并相同并发请求，执行中至少间隔 30 秒刷新，失败冷却 60 秒。SQLite 缓存按模型绑定和证据失效，每个 Bot 保留最近 32 份分析。折叠的后台面板、历史处理区块和隐藏页面不发起分析。失败时保留真实执行明细及重试入口。

## 存储与迁移

Bot 数据库保存会话、记忆、渠道凭据、审批、任务和出站交付。SQLite 使用 WAL、有界锁等待和支持加密的原生 Node 驱动。暂存转换验证 schema、行数、rowid、自增高水位、整数和 BLOB；不支持的虚拟表拒绝转换，不产生半转换库。

数据与工作目录迁移在渠道/调度器之前执行。当前和待应用路径分开，已有目标不合并，链接和中断状态明确。SQLite 原生扩展须匹配 OS/架构/Node ABI；准备脚本拒绝跨架构直接复制。

## 打包

prepare 脚本使用锁定依赖并构建后端/UI，stage 脚本将运行时与许可放入服务包。Tauri 从根 Bot 目录打包，不在桌面包复制源码。

内置技能、persona 和模板属于运行输入，不是公开部署指南；文档维护不能改变它们的入口和语义。第三方许可保留原文。
