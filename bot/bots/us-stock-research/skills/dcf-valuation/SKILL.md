# 现金流折现

目的是把假设摆出来，让用户看清结论依赖什么。结果是一个区间和几条假设，不是真实价值，也不是买卖建议。每次研究只做一次。

## 步骤

1. **历史数据**：用 `sec-data` 取至少 5 年的经营现金流和资本开支，自由现金流 = 经营现金流 - 资本开支。再取收入、长期债务、现金和最新流通股数。记下每个数字的 accession。
2. **假设**：一条一条列出来，每条写清依据：
   - 未来 5 年的自由现金流增长率：参考历史增速，给基准、乐观、保守三组。
   - 折现率：明确说这是判断，不是来自 EDGAR 的数据。常用 8%–12%，按公司的债务和业务稳定性说明为什么选这个值。
   - 永续增长率：不超过长期名义 GDP 增速，通常 2%–3%，且必须低于折现率。
3. **计算**：用命令算，不要心算。每年现金流按 `CF / (1 + r)^t` 折现。终值 = `CF₅ × (1 + g) / (r - g)`，再按第 5 年折现。企业价值 = 两者之和；股权价值 = 企业价值 - 长期债务 + 现金；每股价值 = 股权价值 / 流通股数。
4. **敏感性**：报告放一张表，横向是折现率，纵向是永续增长率，各取 3 到 5 个值。说清楚最影响结果的两三个因子，以及终值占企业价值的比例。这个比例很高时要明确提醒。
5. **和股价比较（可选）**：EDGAR 没有股价。用户给了价格，或者用 `web_search` 查到了，才比较，并写明来源和时间。查不到就不比。

## 写进报告

- 把三组假设和各自的结果都放进去，不要只写一个数字。
- 明确写：这是基于上述假设的估算，改动假设结果会明显变化。
- 自由现金流为负或波动很大、金融公司、早期公司不适合这个方法。遇到这些情况要说明，只给假设和局限，不硬算一个价格。
